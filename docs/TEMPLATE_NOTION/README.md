## Protocollo per i nuovi template

1. Ricercare una fonte unica `TPLUX-REF-NNNN` nell'[archivio centrale](https://github.com/riccardopinato/Idee-app-Archivi-riferimenti/tree/main/17-RICERCA-TEMPLATE-UX).
2. Assegnarla solo quando coerente col Product Bible e con il codice dell'app; mantenere status E0 titolo, E1 descrizione, E2 file esportati, E3 codice donor verificato.
3. Aggiornare `README.md` e `CATALOGO.json` con ID locale stabile; un eventuale modello premium dovrà essere **originale e nativo di Notification Control**, non una copia Notion.
4. No file ZIP, foto o dati personali, segreti, modelli esterni, nuove API/pagamenti, APK o roadmap mutata da una semplice scheda.
